# v0.4.0 작업 메모 (애니 연출판)

요청(2026-11-13 22:05): "좀 더 일본 셀셰이딩 애니메이션 같은 그림체에 매우 과장된 각도와 표현, 기합 같은 걸.
마치 애니메이션을 보듯이. 캐릭터들 생김새도 좀 더 개성있게. 힉스필드는 필요하면 써도 된다."

## 방침
- 브랜치 `cel-shading`(v0.3.0 커밋 c07d349) 위에서 작업. `main`(설치판 v0.2.1)은 건드리지 않음. 푸시는 사용자가 말할 때만.
- 3D 셀 애니 격투 연출: 얼굴은 2D 페인터 하나(`src/26-face.js`)로 3D 머리 텍스처와 컷인 그림을 같이 만든다.

## 할 일
1. `src/26-face.js` FACE: 애니풍 얼굴 페인터, 표정(idle/kiai/hurt/rage), 컷인 그림. 캐릭터별 `look.face`.
2. `src/30-models.js` makeRider: helm 종류 추가(none=맨머리 삐죽머리, wing=날개 투구), 뒷머리(hairBack), 체격(bulk).
   `src/65-rig.js`: 적 상태에 따라 표정 텍스처 교체.
3. `src/50-fx.js` F2: 집중선(focus), 임팩트 프레임(impact), 말풍선 기합(kiai), 컷인 밴드(cutin).
4. `src/90-main.js` Cam: 컷 카메라(G.cut: low/face). `src/70-game.js`: 등장·격노·강공격·완벽 쳐내기·오의·격파에 연결.
5. 기합 목소리: Higgsfield 오디오(mirelo_text_to_audio 등). 2026-11-13 22시대에 MCP 서버가 503/타임아웃으로 끊김 →
   다시 붙으면: 잔액 확인(끊기기 전 4751.63 크레딧) → get_cost → 생성 → Higgsfield sandbox_exec에서 ffmpeg 변환.
   작업공간은 Higgsfield CDN에 못 나갈 수 있음(프록시 허용 목록). 받는 경로부터 확인할 것.
6. 검증 → package.json 0.4.0 → `node build.js release` → CHANGELOG → 커밋 → 아티팩트 재게시
   (slug 5b107fd4-f402-4f67-8531-100b0735696d, 현재 라이브 버전 1794574983-cc35 = v0.3.0).
